# 云程 AutoVoyage · 爱车首页

实施规范 V0.5；适用车主 Web / H5。授权概念跑车的离线渲染素材与静态 WebP 接入已实施，尚待页面验收与发布，实际线上版本以验证记录为准。
全局视觉与交互遵循 [MASTER.md](../MASTER.md)，本文只补充页面规则。

## 页面目标与结构

- 底部固定五项导航：爱车、找店、报修、消息、我的；当前页为爱车。
- 桌面使用水平主导航，手机隐藏水平导航并显示上述五项底栏。
- 顶部放品牌与多车切换；切换车辆后同步刷新车辆数据、保养项目和待办。
- 首屏依次呈现车辆概况、已确认里程与数据日期、最需处理的保养事项。
- V0.5 主卡改用授权 Car Concept 模型离线渲染的银白概念跑车：低视角前 3/4 构图、烟黑玻璃和柔和阴影，透明背景融合海洋蓝主卡。此项为模型改编渲染，不称原创建模，不对应车主实际车型，明确标为外观示意。
- 车辆运行时只加载项目静态 WebP：`/images/vehicles/studio-silver.webp` 为 1440 × 504、69,370 字节，小图 `studio-silver-small.webp` 为 720 × 252、31,214 字节。原 GLB 与 Three.js 只用于本地工作室，不能进入车辆组件的运行依赖。
- 组件提供 720w／1440w `srcset`，图片声明 1440 × 504 宽高并使用响应式 `sizes`；首屏 eager／high，档案 lazy，解码为 async。按实际视口和像素密度选择图片，不承诺手机一定下载小图；页面效果与实际网络选择待浏览器验收。
- V0.4 Cybertruck 灵感楔形皮卡 SVG 为历史设计；V0.5 保留海洋蓝布局与信息层级，替换其车形。
- 主卡采用深海蓝到海水蓝的渐变与克制波纹，信息与按钮使用高对比颜色；里程与日期有独立分隔，更新按钮在手机端占满可用宽度。完整保留车身，不因卡片尺寸裁断车头或车轮。
- 登录与车辆档案复用车辆视觉组件及同一套离线渲染素材；显示尺寸适配各自容器，完整保留车头和车轮。授权来源、CC BY 4.0 署名与修改说明见 [素材署名](../../../docs/image-attribution.md)；历史实拍记录继续保留。
- 首页推荐门店与门店列表共用原创汽车服务站 SVG。首页采用紧凑图标，蓝色檐口、玻璃工位与汽车表达养护场景，4S、连锁与综合维修使用不同招牌装饰；店名和类型仍为文字，不以插画暗示真实店面或认证。
- 保养清单按项目显示状态、时间阈值、对应里程阈值与手册依据。
- 上传里程作为明确操作入口；报修入口可达，避免与保养提醒混为一类。
- “车辆档案”快捷入口通向行驶证识别与车辆资料管理；行驶证没有累计里程，不从证件推测车辆里程，也不替代仪表 / 车厂截图上传。
- 爱车服务入口成组，桌面四列、手机两列；下方保养清单与服务待办组成第二层，避免所有模块同等强调。

## 状态与关键交互

- 里程显示来源和数据时间；未知日期、缺失字段、过期数据明确标记。
- 每个保养项目分别显示未到期、临近、已到期或资料待补充；不汇总成虚构健康分。
- 时间或里程满足手册的先到规则即可到期；资料不足不能显示“无需保养”。
- 上传流程：选择本人车辆 → 选图／可用时拍照 → 识别处理中 → 核对原图与候选字段 → 用户确认 → 校验与入库结果。
- 核对页支持修改候选值、单位与数据时间；未识别字段留空并说明，不猜测。
- 识别失败、异常里程或提交失败保留最后有效记录，并提供重试／补充路径。
- 只有用户确认且校验成功的数据参与重算；成功信息须以服务端结果为准。
- 完工后只更新实际完成且车主确认的项目，未完成项目继续显示原周期。

## 视觉与响应

- 画布使用 `--color-background`，项目卡片使用 `--color-surface`，车辆主卡使用海洋蓝渐变。
- 海洋蓝来自中国海洋大学海洋文化的设计灵感；`#003B70` 深海蓝、`#0068B5` 海水蓝、`#00A7C8` 青蓝与 `#F1F7FB` 海雾底色为云程自定配色，不作为学校官方 VI 声明。
- 主操作使用 `--color-primary`；正文和辅助信息分别使用 `--color-text`、`--color-text-muted`。
- 状态使用 `--color-warning`、`--color-danger`、`--color-primary` 配合图标和文字，避免只用颜色。
- 导航和主操作适配安全区与软键盘；正文可放大，核心触控目标至少 44 × 44 CSS px。
- 为初次无车、加载、无规则、数据待补充、识别失败、会话过期设计独立反馈。

## 评审关注

- 五项导航均可理解，车辆与数据归属清楚。
- 用户能区分识别候选值、已确认里程和各项目的到期依据。
- 示例车型、里程、图片和记录标为演示数据，不能暗示真实采集或实车验证。
- V0.5 验收需确认透明 WebP 无拉伸、裁轮或黑色矩形底，首屏预留图片空间；网络中只有静态车图请求，无 GLB／Three.js 车辆依赖。图片失败仍可读车辆资料并操作，不能以参考画面代替实际页面验收。
