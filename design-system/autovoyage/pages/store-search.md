# 云程 AutoVoyage · 地图找店与预约

实施规范 V0.4；适用车主 Web / H5，依据当前 `StoresPage`、`StoreMap` 与 `StoreIllustration` 实现整理。本文描述代码行为，不声明 V0.4 已部署；实际浏览器验收和线上版本以 [验证记录](../../../docs/verification.md) 为准。
全局视觉与交互遵循 [MASTER.md](../MASTER.md)，本文只补充页面规则。

## 页面目标与结构

- 页首说明同项目、同方案比价，提供“查看门店地图”与主动定位入口；没有车辆档案时提示先建档。
- 搜索面板包含搜索参考位置、门店名称／地址、车辆、服务日期、多选服务项目、各项目的材料与范围、门店类型和距离范围。
- 结果区显示当前匹配门店数量、排序与地图显隐按钮；桌面为门店列表与侧边地图，手机为地图在前、单列门店在后。当前结果直接呈现，不描述为分页或可展开列表。
- 门店卡片显示服务站示意图、序号、名称、类型／演示标记、地址、营业时间、直线距离、项目报价与总价状态；预约弹窗显示各项范围、费用、有效期与时段。

## 门店插画与选择联动

- 列表和首页推荐共用原创 `StoreIllustration` SVG：海洋蓝檐口、玻璃维修工位、前视汽车与举升机；列表使用完整版本，首页使用省略部分细节的紧凑版本。
- 4S、连锁与综合维修主体一致，招牌分别使用盾形轮廓、三枚浅蓝圆点和交叉工具线条；装饰不代替真实店名、类型或审核文字，不表示门店实景。
- SVG 作为装饰对辅助技术隐藏；列表图标使用有名称的按钮，名称为“在地图查看＋门店名”。序号与当前结果顺序及地图标记一致。
- 点击图标或店名会选中并突出对应卡片；地图显示时移动到相应门店，标记同步高亮。点击地图编号则选中对应卡片并滚动到其位置；地图隐藏期间仍保留选择状态。

## 搜索与地图规则

- 初始使用“青岛市中心 · 搜索参考位置”，不冒充用户当前位置。用户可主动定位、点击地图换点，或在位置弹窗输入名称及 WGS84 经纬度；当前未实现地址地理编码搜索。
- 定位不支持、被拒绝或超时时给出明确提示，保留手选坐标和地图换点路径。位置仅用于本次查询，不持续追踪；公网 HTTP IP 预览的浏览器定位能力另按安全上下文限制验收。
- 门店类型支持全部、连锁、综合维修、4S；距离支持不限、3／5／10／30 km。距离按搜索中心与门店坐标计算直线距离，明确标注，不能解释成道路里程或到店时间。
- 地图与列表使用同一筛选结果，仅呈现已审核门店。默认先显示完整固定报价，再在同组内按距离排序；部分支持／需询价单独标识。只有所有所选项目均锁定材料与范围，才允许按完整项目组总价排序。
- 日期变化请求该服务日的有效报价；加载期间不沿用旧日期价格，失败显示“重试价格查询”。车辆、项目、材料方案、门店类型、名称／地址、距离和搜索位置变化后重新计算适配结果。
- 故障咨询入口锁定原车辆、原门店与诊断项目，并明确固定诊断费不包含后续维修总价。

## 真实底图、加载与恢复

- 默认 `osm` 配置使用 MapLibre GL 渲染 OpenFreeMap 的 Liberty 矢量样式，展示真实道路及地理数据；该服务无需地图 API Key，仍依赖浏览器 WebGL 与外部样式、字体和瓦片连接。配置为 `amap` 时改用高德，需要相应 Key 与安全配置。
- MapLibre Worker 通过 Vite 的 `?worker&url` 作为构建资源输出，再由 `setWorkerUrl` 指定同源资源，避免打包后默认相对 Worker 路径失效。地图资源可加载与 Worker 可达应分别验收。
- 搜索中心显示蓝点；门店显示可点击的编号按钮，提供名称、选中状态和可见焦点。地图包含中文缩放控件，关闭滚轮缩放与旋转；可拖动浏览，点击空白位置更新搜索中心。
- 门店按声明的 WGS84／GCJ02 坐标系转换，默认矢量底图使用 WGS84，高德显示使用 GCJ02；距离计算统一到 WGS84。结果变化时更新同一组标记，必要时调整范围容纳搜索中心和门店。
- 加载状态显示“正在加载地图…”并设置忙碌状态；默认矢量地图收到瓦片数据且进入无资源错误的空闲状态后才显示就绪。移动视口重新进入加载判断，不用空白画布冒充加载成功。
- 底图连接失败、部分资源失败、加载超时、WebGL 不可用或绘制中断都有具体提示和“重试”；重试销毁并重建地图。失败时保留门店列表与现有筛选，列表可继续使用。
- “隐藏地图”卸载地图并切换为列表布局；“显示地图”重新创建并加载地图。“查看门店地图”会显示地图并滚动到地图区域。容器尺寸变化通过 `ResizeObserver` 调整 MapLibre 画布。
- 默认地图右下保留 OpenFreeMap、OpenMapTiles 与 OpenStreetMap 的自动署名；截图和发布页面需保留来源，高德亦按其要求显示来源。具体素材与许可见 [图片及地图署名](../../../docs/image-attribution.md)。

## 价格与预约规则

- 固定价显示完整总额，预估价显示区间，待报价显示“需询价”；缺项、预估或询价不作为零元加入完整总价。
- 比价口径由车型、所选项目、服务日期及各项材料规格、包含／不含范围和税费组成；未锁定时注明“口径尚未锁定”，不开放价格排序。
- 预约弹窗逐项显示报价版本、材料规格、包含／不含项、含税口径、有效期、材料／工时／其他费用及总价；只有完整固定项目组能提交确定总价预约。
- 时段按所选门店、日期和有效状态筛选，显示北京时间及剩余名额，已满时段禁用，无时段时提示换日期。查看报价不预留名额。
- 用户选择时段并勾选核对后提交，附带报价版本和请求标识；报价变更或日期变化重置核对状态，提交期间禁用提交按钮。失败显示服务端原因并刷新数据，成功提示“预约已提交，等待门店确认”。

## 视觉与响应

- 页面与面板使用 `--color-background`、`--color-surface`；边界使用 `--color-border`。
- 选中标记、主操作和交互文字使用 `--color-primary`；`--color-brand-accent` 仅用于装饰点缀。
- 价格状态配文字说明；异常使用 `--color-warning` 或 `--color-danger`。
- 海洋蓝门店示意图在桌面约 106 × 100px，手机约 88 × 90px；保留完整 SVG，避免原图裁断或挤压文本。手机筛选可换行，输入与选择框使用 16px 字号。
- 桌面侧边地图随列表保持可见，手机取消侧边粘滞布局并将地图放在列表前；通过显隐按钮获得纯列表布局，地图缩放按钮和编号标记为 44 × 44 CSS px。
- 加载／错误提示与地图来源分区显示，保留可操作重试按钮。减弱动态效果时关闭加载旋转，并减少程序平移和列表滚动动画；不以动画结束决定业务结果。

## 评审关注

- 用户能识别当前筛选条件、地图范围、距离口径和可比较价格。
- 图标、店名、地图标记选中状态一致；显隐、重试和调整窗口后仍能加载真实底图，所有显示的门店来自同一结果集。
- 定位拒绝、无结果、地图故障、价格查询失败、缺项、询价、变价和满额均有明确提示；无结果提供重置筛选入口。
- 演示门店、地址与价格显式标注；代码实施、浏览器验证与线上部署分别记录，不能用静态规范替代验收证据。
