## 事实来源与去重

官网新增表为 goodsId **152（2026秦PLUS DM-i）、150（2026宋L DM-i）、151（2026夏）、10051（2026海狮06DM-i）、10041（2026海狮06EV）、10011（2025海豚）**。表头必须明确写年款，车型名称与动力参数使用同一列。夏的“218KM卓越型 舒享选装包”是官网明确列出的独立列，保留其完整名称。海豚普通2025款与2025智驾版分别保留，时尚版电机功率不能跨版本借用。

汽车之家数据由公开车系页面自身调用的 `https://www.autohome.com.cn/web-main/car/series/getspeclistresponse` 返回。只使用无需登录的公开事实；`seriesid` 绑定已核实的车系；`tagid=1` 提供当前公开候选，页面列出的2024–2026停售年款再按其原`yearvalue`、`yearname`读取。逐条要求名称开头的“YYYY款”与原`year`字段一致，并只接受已上市/停售记录。没有跨记录组合年款、动力和配置。

动力保留同一记录的燃料、马力、变速箱与驱动。纯电车型的马力标为电机；插混车型的马力标为发动机，**不作为油电系统总功率，也不与电机马力相加**。官网记录沿用官方kW，门户记录保留原马力，不人为换算制造精度。配置内的续航数字保留原名称，不作为每辆实车的保证续航。

稳定ID：官网为 `official-byd-recent-{goodsId}-{配置名哈希}`，门户为 `autohome-byd-spec-{具体车型ID}`。精确核对的12个既有官网配置、22个本次由官网替换的门户配置，按原门户具体车型ID排除。新增官方配置23条中，夏的舒享选装包没有等价的门户记录。数据加载器合并其他来源时应继续优先保留上述官网事实；同一车系、年款与配置的名称空白、KM大小写或门户额外动力前缀不能据此生成重复候选。

来源记录保存用户可访问的HTTPS车系/参数页面、检索日期、事实快照说明和输入SHA-256摘要。公开访问不等于开源整站许可；本项目仅保存车型短名称和少量事实，不分发完整页面、图片、Logo、报价或整张配置表。

## 构建与检查

构建脚本：`scripts/build-byd-recent-variants.mjs`。它只解析本次研究已缓存的JSON，不在构建或部署时自动请求第三方网站；需保留本地被Git忽略的 `.local/variant-research/autohome-byd` 与 `byd-current` 研究输入。新的来源快照应先重新访问并核对上述公开页面，再调整映射与精确替换ID，审阅输出后提交，不能直接将抓取成功当作事实核验完成。

```sh
node scripts/build-byd-recent-variants.mjs
```

脚本验证：385个ID唯一、全部车系与来源引用存在、名称年款与year一致、证据非空、动力与配置组合不超过正式车型字段200字符、证据不超过1000字符，同一型号不会在多个查询结果重复保留。来源和车型新目录由主加载器统一合并。最终导入前仍应核对车辆登记信息与实车配置；本补充不会自动决定保养手册适用性。
