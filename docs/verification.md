## 数据隔离要求

开发联调使用 `PGSCHEMA=av_development`；公共课程预览使用 public 中的本项目 `av_` 表。两者不得混用演示账户或运行中的业务记录。

`npm run test:postgres` 会创建随机 `av_test_*` schema，以真实 PostgreSQL 执行并发名额、幂等、越权、取消释放和价格冲突回滚等检查，结束后只清理该临时 schema。PGlite 内存回归不能替代真实 PostgreSQL 并发证据。

公共预览的一次性初始化会写入目标数据，日常容器关闭自动种子。账号口令、数据库密码、会话密钥、原始照片和 AI 密钥不得写入本验证记录或提交到 Git。

## 关键回归清单

- 本人 / 本店 / 专家分配范围的服务端校验，照片与站内消息权限隔离，退出撤销会话。
- 最后一个预约名额的并发争抢、重复请求幂等、幂等键内容冲突、取消 / 拒绝 / 超时只释放一次。
- 同一时刻的 `Z` 与 `+08:00` 日期表达不能绕过时段重叠或车辆冲突；月末周期与上海时区凌晨完工基准正确。
- 价格版本变化与过期报价拒绝提交，失败事务不占名额，历史价格快照不被新版本覆盖。
- 增项、减项与材料 / 费用变化由车主明确确认；完工只能选择批准后的实际项目，归档只重算确认完成的项目。
- 车型明确列出适用保养项目；纯电车型不误报发动机机油需求，适用范围或手册缺失时明确提示资料待补充。
- 重复图片、旧图、未来日期、未知单位、里程回退与异常增长不得覆盖最后有效观测；识别未确认前不参与保养计算。
- 地图与列表使用相同查询结果，直线距离有口径说明，定位拒绝可手选，地图故障不误报加载成功。

## 尚需独立验收的能力

**真实 AI 识别**：服务未配置时必须在真实上传后明确显示识别不可用，不能以空候选值、手工模拟值或人工确认代替“AI 已成功识别”。有效服务配置和真实样本的完整闭环、字段修正率与失败类型需要独立记录，当前不承诺未经实测的准确率。

**地图服务**：OpenStreetMap 真实底图的目标网络可达性、高德 Key / 安全配置、实际访问来源限制与额度分别核验。列表降级可用不等于真实地图及联动已通过。IP HTTP 预览下浏览器定位通常受安全上下文限制，不作为定位授权、拍照入口或 HTTPS 安全会话已验收的证据。

**真实车型规则**：课程演示规则必须保持演示标识。至少需要按具体年款与动力配置核对实际车型手册来源及适用项目，区分首保与后续周期、总里程与发动机里程，完成后才能用于真实车辆判断。

**真机与性能**：手机 Safari、Chrome、微信浏览器的照片方向 / 格式、文件选择、定位授权、安全区、软键盘与文字放大，以及 20 并发查询用户、1,000 条合成门店服务数据的 P95 基线，均需在记录配置的实际环境执行，不从开发构建成功推断。
