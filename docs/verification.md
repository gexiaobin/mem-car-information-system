## 数据隔离要求

开发联调使用 `PGSCHEMA=av_development`；公共课程预览使用 public 中的本项目 `av_` 表。两者不得混用演示账户或运行中的业务记录。

`npm run test:postgres` 会创建随机 `av_test_*` schema，以真实 PostgreSQL 执行并发名额、幂等、越权、取消释放和价格冲突回滚等检查，结束后只清理该临时 schema。PGlite 内存回归不能替代真实 PostgreSQL 并发证据。

公共预览的一次性初始化会写入目标数据，日常容器关闭自动种子。账号口令、数据库密码、会话密钥、原始照片和 AI 密钥不得写入本验证记录或提交到 Git。

本次公共预览已完成一次性初始化，四类账号使用独立随机口令；运行配置为 `NODE_ENV=production`、`DEMO_MODE=false`、`SEED_DEMO=false`、`ALLOW_HTTP_PREVIEW=true`。Portainer 的 17 个私有环境变量已逐项核对一致。env 上传时外围引号会被作为实际值保留，已改用专用无外围引号的导入文件并纠正表单值。私有配置和账号文件均保持未跟踪。

云端首页、手机宽度首页、预约预览与容器健康截图保存在本机忽略目录 `.local/screenshots/`，文件分别为 `cloud-owner-desktop.jpg`、`cloud-owner-mobile.jpg`、`cloud-booking-mobile.jpg`、`cloud-stack-health.jpg`。
