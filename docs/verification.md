## 数据隔离要求

开发联调使用 `PGSCHEMA=av_development`；公共课程预览使用 public 中的本项目 `av_` 表。两者不得混用演示账户或运行中的业务记录。

`npm run test:postgres` 会创建随机 `av_test_*` schema，以真实 PostgreSQL 执行并发名额、幂等、越权、取消释放和价格冲突回滚等检查，结束后只清理该临时 schema。PGlite 内存回归不能替代真实 PostgreSQL 并发证据。

公共预览的一次性初始化会写入目标数据，日常容器关闭自动种子。账号口令、数据库密码、会话密钥、原始照片和 AI 密钥不得写入本验证记录或提交到 Git。

本次公共预览已完成一次性初始化，四类账号使用独立随机口令；运行配置为 `NODE_ENV=production`、`DEMO_MODE=false`、`SEED_DEMO=false`、`ALLOW_HTTP_PREVIEW=true`。Portainer 的 17 个私有环境变量已逐项核对一致。env 上传时外围引号会被作为实际值保留，已改用专用无外围引号的导入文件并纠正表单值。私有配置和账号文件均保持未跟踪。

云端首页、手机宽度首页、预约预览与容器健康截图保存在本机忽略目录 `.local/screenshots/`，文件分别为 `cloud-owner-desktop.jpg`、`cloud-owner-mobile.jpg`、`cloud-booking-mobile.jpg`、`cloud-stack-health.jpg`。

云端门店工作台截图为 `.local/screenshots/cloud-store-desktop.jpg`。切换下一角色时，浏览器扩展无法验证当前页面地址并停止自动控制，因此本次未继续云端专家与平台角色的浏览器验收；不将已实现的角色界面推断为已通过该项云端验收。

## 关键回归清单

- 本人 / 本店 / 专家分配范围的服务端校验，照片与站内消息权限隔离，退出撤销会话。
- 最后一个预约名额的并发争抢、重复请求幂等、幂等键内容冲突、取消 / 拒绝 / 超时只释放一次。
- 同一时刻的 `Z` 与 `+08:00` 日期表达不能绕过时段重叠或车辆冲突；月末周期与上海时区凌晨完工基准正确。
- 价格版本变化与过期报价拒绝提交，失败事务不占名额，历史价格快照不被新版本覆盖。
- 增项、减项与材料 / 费用变化由车主明确确认；完工只能选择批准后的实际项目，归档只重算确认完成的项目。
- 车型明确列出适用保养项目；纯电车型不误报发动机机油需求，适用范围或手册缺失时明确提示资料待补充。
- 重复图片、旧图、未来日期、未知单位、里程回退与异常增长不得覆盖最后有效观测；识别未确认前不参与保养计算。
- 地图与列表使用相同查询结果，直线距离有口径说明，定位拒绝可手选，地图故障不误报加载成功。

**云端 AI**：部署后通过公网应用的 375 像素手机宽度界面实际上传上述合成仪表图，真实服务返回累计里程 12345 km，未知拍摄日期保持空白，界面明确要求车主核对后确认。关闭弹窗时未确认候选值，回到首页后原车有效里程仍为 1,680 km；本次只保留待确认的合成图片识别记录，没有将测试里程写入公共车辆。验收截图保存在本机忽略目录 `.local/screenshots/cloud-ai-review.jpg`。
