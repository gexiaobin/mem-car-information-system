# 常规保养项目摘要

V0.9.5将AI查找结果的默认视图改为“常规使用下的主要保养项目／官方要求”。此前103条识别结果把软管检查、紧固、常规检查与更换、不同严苛工况混在主表中，数量不等于日常保养项目数。开发与部署验收状态见[验证记录](verification.md)。

主要项目按原件实际存在的油液、滤芯、火花塞等部件整理。正常使用下有更换要求时优先展示更换；只有检查要求的变速器油仍显示检查，不套用参考服务目录的更换动作。不同车型的项目数量可以不同，纯电车型不会补出机油或火花塞。

机油与机滤、分动器与后差速器仅在要求完全相同且没有差异条件时合并显示；不同首次／后续周期、操作、条件和里程口径不强行合并。显示项目数不等于独立规则数。阈值取自已有结构化识别结果，摘要本身不再调用AI，不生成原件未给出的数字。

原文有时间和公里两种限制时显示先到者，首次与后续不同则分别展示。仪表保养提示及原件明确的兜底时间／里程仍可属于常规要求。多尘、重载、拖挂、长期怠速等条件作为可展开补充；软管与螺栓等完整识别细目可按需查看。待核对条目保持提示，原文引用及来源链接保留。

“带入核对”只取主表对应的常规原始规则进入草稿，服务端重新计算标准项目关联，避免严苛工况重复行造成关联冲突；没有准确对应的项目继续留空。归并展示不会把不同动作或部件合成一条规则，也不会把原来未勾选的条目改为勾选。来源原件与证据页继续保存，已有手册和规则不会被升级自动修改。

查询结果仍保留完整原始条目。`POST /admin/manual-imports/from-ai-answer`可显式传`scope:"common"`，省略时也使用该范围。没有主要常规项目时提示核对原件，不退回导入全部细分项目。原有图片识别与手动规则编辑保持原有流程，本次精简针对AI查找结果及其带入流程。

摘要适用于不同品牌的已有识别结果，不依赖汉兰达的数量或周期；它不扩大网上手册来源覆盖。官方目录直连目前覆盖广汽丰田，其他品牌仍可能遇到检索或下载限制。车型版本、适用范围及未完成的AI候选仍需核对。
